# TASK-20260528-001 — Fix lỗi 413 khi upload file CMS

## Entries

### [2026-05-28] INSPECT — Xác định nguồn lỗi 413
- Kiểm tra `src/app/api/admin/uploads/route.ts`: upload API ban đầu cho phép file tối đa 50MB.
- Kiểm tra `ops/nginx/xuanhoa.conf`: Nginx mẫu ban đầu đang đặt `client_max_body_size 60m`.
- Kiểm tra `src/proxy.ts`: matcher bảo vệ `/api/admin/:path*`, nên request upload đi qua Next proxy.
- Xác nhận Next 16 mặc định `proxyClientMaxBodySize` là 10MB, thấp hơn giới hạn upload của app.

### [2026-05-28] FIX — Đồng bộ giới hạn upload
- Thêm `experimental.proxyClientMaxBodySize` trong `next.config.ts`.
- Tăng upload API lên giới hạn nghiệp vụ 300MB và khai báo runtime Node.js cho route ghi file.
- Ghi file upload bằng stream thay vì `arrayBuffer()` + `Buffer.from()` để giảm áp lực RAM với file lớn.
- Thêm validate phía client để chặn file quá 300MB hoặc sai MIME trước khi gửi request.
- Bổ sung xử lý response `413` không phải JSON để admin thấy lỗi rõ ràng.
- Cập nhật sidebar admin dùng logo phường `/branding/xuan-hoa-logo.png`, đồng bộ với trang login admin mới nhất.
- Đặt giới hạn proxy/Nginx mẫu ở 310MB để chừa overhead multipart cho file 300MB.
